Projectes personals

M'agrada experimentar amb pàgines web senzilles i eines d'intel·ligència artificial. Alguns projectes els faig per practicar i aprendre noves formes de crear aplicacions.

  • Pàgina web personal creada amb HTML.
  • Proves de prompts per obtenir millors respostes d'eines d'IA.
  • Idees de petites aplicacions creades amb ajuda d'intel·ligència artificial.

Passos per crear un projecte

  1. Pensar una idea o necessitat.
  2. Preparar l'estructura del projecte.
  3. Utilitzar HTML i eines d'IA per desenvolupar-lo.
  4. Provar el resultat i corregir errors.
  5. Publicar-lo a GitHub.
