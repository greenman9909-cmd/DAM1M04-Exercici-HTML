# DAM1M04-Exercici-HTML

Exercici 000 de Llenguatge de Marques: currículum web d'un alumne.

## Fitxers

- `index.html` — presentació personal.
- `estudis.html` — estudis i coneixements.
- `projectes.html` — projectes personals.
- `imatges/` — imatges utilitzades a les pàgines.

Projecte fet amb HTML bàsic per practicar estructura, navegació, llistes, imatges, enllaços i elements semàntics.
